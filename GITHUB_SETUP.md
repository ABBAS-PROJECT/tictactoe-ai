# GitHub Upload Instructions

## Quick Setup (5 minutes)

### Step 1: Create Repository on GitHub

1. Go to https://github.com/ABBAS-PROJECT
2. Click "New repository"
3. Name: `tictactoe-minimax-ai`
4. Description: `Tic-Tac-Toe with unbeatable AI using Minimax algorithm - C++ beginner project`
5. Make it **Public**
6. DON'T initialize with README
7. Click "Create repository"

### Step 2: Upload Files

**Option A: Web Upload (Easiest - 3 minutes)**

1. Go to your new repository
2. Click "uploading an existing file"
3. Drag and drop ALL files:
   - main.cpp
   - README.md
   - Makefile
   - .gitignore
4. Commit message: "Add Tic-Tac-Toe with Minimax AI"
5. Click "Commit changes"

**Option B: Git Command Line**

```bash
cd tictactoe-ai

git init
git add .
git commit -m "Add Tic-Tac-Toe with Minimax AI"
git remote add origin https://github.com/ABBAS-PROJECT/tictactoe-minimax-ai.git
git branch -M main
git push -u origin main
```

### Step 3: Verify

1. Visit: https://github.com/ABBAS-PROJECT/tictactoe-minimax-ai
2. README should display nicely
3. All files should be there

### Step 4: Test It Yourself

Before submitting, make sure you can:
1. Compile the code: `g++ main.cpp -o tictactoe`
2. Run it: `./tictactoe`
3. Play a game against the AI
4. Explain how Minimax works
